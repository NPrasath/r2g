# Lab 04 · Agent-assisted development

**Lead:** Developer. **Partners:** Tester and Technical Manager.

1. Select one Ready implementation issue and create a focused branch.
2. Give Implementation Developer the approved requirement/version, accepted design, criteria/test IDs, scope, skill path, and check commands.
3. Inspect the agent's plan and diff. Return new business choices to the BA; explain the resulting code yourself.
4. Add meaningful unit/component/integration tests for the agreed behavior. Run the available checks and inspect real CI logs.
5. Open a draft PR using the template. Link actual commands/results and note environments or tests not run. Include security/data/rollback implications as applicable.
6. Record actual prompting, review, correction, and verification effort. Ask for human technical review and independent QA once the candidate is ready.

**Deliverables:** bounded implementation PR, developer tests, actual check evidence, AI run record.

**Exit:** the change is reviewable and a specific candidate is available for QA. A generated implementation alone is not Done.
