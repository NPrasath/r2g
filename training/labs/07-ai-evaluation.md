# Lab 07 · Evaluate AI and improve a skill

**Lead:** Technical Manager. **Participants:** all four roles.

1. Gather the actual AI run records, PR corrections, review findings, test evidence, and defects.
2. Use [the evaluation method](../../docs/ai-evaluation.md) to count human effort across all roles. Leave savings blank if no comparable measured baseline exists.
3. Identify one recurring issue in prompts or outputs. Propose a small skill/instruction change, rather than adding broad text without a demonstrated need.
4. Evaluate the revision on a fresh comparable task and record the result and human corrections. Do not reuse the expected answer as the only evaluation.
5. Submit the revised skill/instruction through a PR and record the Technical Manager's decision.
6. Rotate roles for the next approved R2G increment.

**Deliverables:** quality/effort retrospective, one evidence-backed improvement PR, next cohort roles/scope.

**Exit:** the team can explain where AI helped, where people corrected it, and which evidence supports the next process change.
