# Lab 00 · Foundation

**Lead:** Technical Manager. **Participants:** BA, Developer, Tester.

1. Complete [repository setup](../../docs/repository-setup.md) and fill TEAM.md through a PR.
2. Open a foundation issue; link this lab and name dependencies/owners.
3. Inspect the CI run for the initial commit. Record the SDK, restore/build/test outcome, run URL, and unavailable checks. Fix failures through a focused PR.
4. Confirm which Copilot profiles/features the cohort can use. Test access with a small documentation task; record the actual surface and limitations.
5. Create the Excel tracking sheets. Agree where the workbook is shared and how IDs link back to GitHub.
6. Configure supported branch controls, or record the manual review procedure if they are unavailable.

**Deliverables:** named roles, foundation issue/PR, actual CI evidence, confirmed tool access, workbook tracking approach.

**Exit:** participants can create issues/branches/PRs and understand what the two smoke cases establish. Missing runtime/agent access is an explicit dependency before the coding lab.
