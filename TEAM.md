# Cohort and role owners

The repository owner appoints people at the start of each cohort. Fill this table in a PR; these are deliberately unassigned.

| Role | Person | GitHub username | Backup |
| --- | --- | --- | --- |
| Business Analyst | Unassigned | Unassigned | Unassigned |
| Developer | Unassigned | Unassigned | Unassigned |
| Tester / QA | Unassigned | Unassigned | Unassigned |
| Technical Manager | Unassigned | Unassigned | Unassigned |

One person can perform multiple roles, but must record separate decisions. Have another person review authored code. A PR author cannot supply their own required GitHub approval.

Rotate roles after a completed increment so that each participant experiences requirements, implementation, QA, and review. Record the cohort name, dates, and rotation here.
